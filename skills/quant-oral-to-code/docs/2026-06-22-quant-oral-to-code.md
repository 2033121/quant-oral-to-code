# quant-oral-to-code

## 高层口径

这个 skill 的目标不是“假装任何口述策略都已经研究完成”，而是把抽象量化语言稳定翻译成：

- 可检查的 `strategy_spec.json`
- 可审计的 `translation_trace.json`
- 统一的 DuckDB 数据契约
- 在数据齐备时可运行的策略代码、回测入口与结果摘要

## 固定边界

- DuckDB 是唯一标准持久化格式
- 缺少真实关键数据时必须进入 `data_required_cutoff`
- 不能用 mock 收益、假回撤、伪 Sharpe 冒充正式回测结果
- 生成代码必须默认规避前视，执行口径应偏保守

## 对外发布口径

如果这个 skill 被安装到其他智能体系统：

- 以当前 skill 目录作为运行根目录即可
- 不应依赖 `.trae`、私有仓库记忆或宿主项目专用目录
- `scripts/validate_quant_oral_to_code.py` 应能在独立安装下自检

## 术语消歧

对“龙头 / 杂毛 / 弱转强 / 承接 / 中枢 / 背驰 / 筹码 / 净流入 / 均价线 / 竞价 / 分歧转一致”等术语：

- 不能静默糊弄
- 必须输出候选定义、说明依赖数据、允许用户补充自定义定义
- 如果答案仍不足以落成规则，应继续保留 unresolved 状态，而不是强行写策略代码
